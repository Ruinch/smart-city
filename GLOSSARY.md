# Термины проекта

- **Mini App** — интерфейс внутри Telegram, который открывается из бота и общается с нашим сервером по HTTPS.
- **Запрос** — свободное описание желаемого выхода вместе с временем, способом передвижения, бюджетом на человека, числом участников и необязательной геопозицией.
- **POI** (point of interest) — конкретное место с координатами и ссылкой на исходную запись OpenStreetMap. Его наличие в OSM не подтверждает часы, цены или атмосферу.
- **Кандидат** — найденный для текущего запроса POI. Кандидаты не показываются на карте до построения маршрута.
- **Поиск мест** — отбор кандидатов по категориям запроса из автоматически собранного городского снимка OSM. Ограниченный внешний запрос может дополнить данные.
- **Маршрут** — упорядоченные 1–3 остановки, выбранные из кандидатов и связанные общей ссылкой на путь. Оценка времени присутствует только там, где её можно рассчитать из доступных данных.
- **Схема пути** — прямая линия между координатами остановок на карте. Это визуальная связь точек, а не проверенная пешеходная или автомобильная дорога.
- **Загородная поездка** — отдельный режим для выезда из Астаны; время дороги и расходы показываются только при подходящих данных с источником.
- **Неизвестная стоимость или дорога** — отсутствие сопоставимой оценки. Это не ноль и не подтверждение попадания в бюджет или время.
- **Факт о месте** — сведения с доступным источником: название, координаты, тип OSM объекта или опубликованные часы работы. Актуальность часов не гарантирована.
- **Свидетельство** — кликабельная ссылка, подтверждающая отдельную характеристику места. Если такой ссылки нет, приложение не заявляет характеристику как факт.
- **RAG** — получение реальных кандидатов по текущему запросу и создание маршрута моделью только на основе найденных мест, с серверной проверкой идентификаторов.
