# Демонстрация по критериям хакатона

Продукт: Telegram Mini App «Рядом» для маршрутов по Астане и поездок из неё. Открывать через [@smart_city_ryadombot](https://t.me/smart_city_ryadombot), чтобы запрос имел действительную подпись Telegram.

## Три основных сценария

1. **Спокойный городской маршрут.** Запрос «Хочу кофе и почитать книгу», 2–4 часа, пешком. При желании выберите старт на карте и ориентир в восточной части города. Покажите последовательность остановок, короткое «почему», расстояние по прямой и ссылку на исходную запись OSM. Тишина не считается доказанной по типу кафе: если источник её не подтверждает, приложение просит проверить на месте.
2. **Вечер для компании.** Запрос «Хочу клуб и танцы с друзьями», 4 часа, 4 человека. Покажите, как параметры меняют подбор и как «Ещё идеи» исключает уже показанные места. Актуальная программа, свободные места и вход не заявляются без отдельного источника.
3. **Поездка из Астаны.** Выберите режим поездки, машину, 12 часов и ориентир в сторону Бурабая. Система предлагает только подходящие по стороне выезда варианты из проверяемого каталога. Она не выдаёт неподтверждённую дорогу, стоимость или открытость за факт.

Для показа интерфейса без поиска: откройте карту, перетащите нижнюю панель, задайте ориентир касанием карты, затем выберите время ползунком от 1 до 24 часов. После поиска покажите отдельную плашку с фактическим направлением от старта к последней остановке. Переключите язык RU → KK → EN и повторно составьте маршрут: серверный текст приходит на выбранном языке.

## Соответствие критериям

| Критерий | Что можно показать | Честная граница |
| --- | --- | --- |
| Релевантность | Свободный запрос → категории → реальные OSM ID → до трёх связанных остановок; редкие категории дополняются ограниченным Overpass запросом. | OSM не содержит буквально все места; 521 непроверенный кандидат Overture не публикуется. |
| Контекст и адаптивность | Точка старта, примерное направление, коридор маршрута, время 1–24 ч, способ передвижения, бюджет на человека, число людей. | Пешее время приблизительно; для транспорта и часов работы данных может не быть. Точный возврат к старту не включён. |
| Объяснения | Каждая остановка сообщает категорию, расстояние по прямой, источник и действие; цена с доказательством включает ссылку и дату. | Неподтверждённые свойства обозначены как неизвестные. |
| UX демо | Карта сразу, понятная панель, точка старта и ориентир на карте, итоговая плашка направления, один основной запрос и «Ещё идеи». | Запрос маршрута работает через действительный запуск Telegram Mini App. |
| Креативность | Маршрут из 1–3 остановок, направление как пользовательский жест на карте, подбор для группы, три языка. | Временные события и полноценная дорожная геометрия пока не интегрированы. |
| Этика и приватность | Координаты используются только в текущем запросе; Overpass получает округлённый центр, модель не получает точные координаты пользователя; источник и неопределённость видны. | Сервисы карты и инфраструктуры получают технические данные соединения. |
| Завершённость | API, бот, карта, локализация, защита Telegram подписи, тесты и ADR. | Для масштабного запуска нужны более надёжный POI-провайдер, дорожное время и мониторинг качества данных. |

## Дальнейшее усиление поиска

1. **Дорожное время и доступная область.** При наличии бесплатного ключа Geoapify использовать маршрутизацию/изохроны для отсечения точек, до которых нельзя добраться за выбранное время. Его Places основан преимущественно на OSM, поэтому сам по себе не решает нехватку независимых POI: [тарифы](https://www.geoapify.com/pricing/), [Places API](https://www.geoapify.com/places-api/).
2. **Новые независимые места.** Проверить кандидатов [Overture Maps Places](https://docs.overturemaps.org/guides/places/) по названию, адресу/филиалу, координатам и исходной лицензии до добавления в маршрут. Файл `data/research/astana-overture-candidates.json` служит очередью проверки, не рабочей базой. Указывать [атрибуцию Overture](https://docs.overturemaps.org/attribution/).
3. **Временные события.** Адресный веб-поиск применять к найденному заведению или афише. Показывать событие только при совпадении места, явной дате/времени и ссылке на организатора или билетную страницу. Без этого писать «программа не подтверждена». В качестве источников для дальнейшей интеграции рассмотреть [Ticketon Astana](https://ticketon.kz/astana?lang=ru) и [календарь QazTourism](https://event.qaztourism.kz/).

Публичный Overpass остаётся ограниченным дополнением к снимку OSM: его [правила использования](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html) предупреждают о перегрузке и неподходящем использовании в массовых приложениях. Веб-поиск OpenAI расходует платный баланс: [официальное руководство](https://developers.openai.com/api/docs/guides/tools-web-search), [цены](https://developers.openai.com/api/docs/pricing). Поэтому запросы ограничены, кешируются и не превращают отсутствующие данные в уверенные утверждения.
