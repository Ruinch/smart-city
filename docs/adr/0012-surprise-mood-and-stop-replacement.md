# ADR 0012: Открытие места по настроению и замена одной остановки

Дата: 2026-10-20

Статус: принято

## Контекст

Обычный запрос собирает до трёх вариантов маршрута из проверяемых записей мест. Пользователю также нужен быстрый способ получить идею без текста, выбрать направление по настроению и поменять одну неудачную остановку без потери остальных. ADR 0004, 0008, 0009, 0010 и 0011 уже определяют ограничения времени, бюджета, доступности, происхождения места и подтверждения его свойств. Новые режимы не должны обходить эти ограничения или объявлять субъективные впечатления фактами.

## Решение

1. **«Удиви меня» — городской запрос в одно нажатие.** Использовать текущие старт, длительность, транспорт, бюджет, число участников и условия доступности. Выбранный ориентир направления не ограничивает этот режим: цель — одно место рядом со стартом. По умолчанию длительность городской прогулки остаётся 120 минут, пока человек её не изменит. Сервер ищет реальные близкие кандидаты через существующий снимок OSM, проверенную часть [Overture](https://docs.overturemaps.org/guides/places/) и ограниченный поиск Overpass при нехватке мест, затем возвращает одну остановку. Разнообразие категорий и исключение уже показанных ID помогают избежать одинаковых предложений при повторном нажатии; ни одна подборка не гарантирует бесконечный запас новых мест. «Необычное» обозначает способ разнообразить подбор, а не подтверждённое свойство заведения. Для поездок из города этот режим не применяется.
2. **Настроение — явное предпочтение категорий.** Шесть вариантов: расслабиться, развлечься, пофотографироваться, узнать новое, побыть в тишине, не знаю. Выбор влияет на категории поиска и их порядок; свободный текст и явные ограничения пользователя сохраняют приоритет. Например, режим тишины может предпочесть библиотеку или сад, но категория не доказывает, что там сейчас тихо. Режим фото не гарантирует удачный вид, а развлечений — действующее событие. При варианте «не знаю» категории намеренно разнообразны. Настроение доступно только для городских маршрутов и может быть снято без очистки остальных настроек.
3. **Замена одной остановки — операция над текущим городским маршрутом.** Передаются ID остановок по порядку, индекс заменяемой точки и одна причина: «слишком далеко», «дорого», «уже был» или «хочу другое». Сервер заново разрешает ID через свои источники; координаты, цену и свойства из браузера он не считает доказательством. Другие остановки остаются теми же и в том же порядке. Кандидат не дублирует уже включённое место или ранее отклонённый ID, отвечает теме запроса и проходит ограничения времени, переходов, бюджета и доступности с учётом соседних остановок. «Слишком далеко» требует уменьшить приблизительную длину маршрута; «дорого» отдаёт предпочтение сопоставимой подтверждённой более низкой цене, но неизвестную стоимость не выдаёт за дешёвую; после успешной замены «уже был» исключает отклонённое место из последующих предложений текущей сессии; «хочу другое» повышает разнообразие. Если подходящей замены нет или источник временно недоступен, старый маршрут остаётся без изменений и приложение объясняет причину. Для загородной поездки замена отдельной точки пока не предусмотрена.
4. **Только подтверждённые места и осторожные объяснения.** OpenAI может классифицировать текст и выбирать только сервером найденные ID с проверкой ответа по [структурированной схеме](https://developers.openai.com/api/docs/guides/structured-outputs); модель не создаёт название, координаты, часы или цену места. Источник каждого POI и отдельные свидетельства о цене или свойствах показываются по правилам ADR 0010–0011. Часы OSM и опубликованная цена могут устареть; отсутствие данных означает неизвестность. Тег [`fee=*`](https://wiki.openstreetmap.org/wiki/Key:fee) не сообщает точную сумму. Нельзя утверждать «сейчас открыто», «точно тихо», «бесплатно», «подходит для фото» или «мест хватит всей группе» лишь по категории или ответу модели.
5. **Приватность и нагрузка.** [Подписанные данные запуска Telegram](https://core.telegram.org/bots/webapps#validating-data-received-via-the-mini-app) проверяются сервером как в обычном запросе. Координаты и причина замены нужны только для текущего подбора; историю посещений, точную геопозицию и профиль настроений приложение не сохраняет на сервере. Для разнообразия достаточно ID мест текущей сессии. Повторные запросы используют существующие ограничения частоты и кратковременный кеш поиска; одно нажатие замены не должно превращаться в неограниченную серию обращений к [публичному Overpass](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html) или OpenAI.

## Следствия

Появляются короткий путь к одному месту, понятный выбор настроения и локальная правка маршрута. Проверки должны подтверждать ровно одну остановку в режиме сюрприза, сохранение остальных ID и порядка при замене, соблюдение жёстких фильтров и отсутствие выдуманных свойств. При неизвестной цене или часах интерфейс сообщает об этом прямо. Оценка пешего времени остаётся приблизительной; для транспорта без дорожного источника точное время не заявляется.
