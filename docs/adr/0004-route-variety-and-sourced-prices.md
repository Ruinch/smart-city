# ADR 0004: Разные маршруты и цены с источником

Дата: 2026-10-19

Статус: принято

## Контекст

Городской снимок OSM содержит гораздо больше мест, чем показывал первый результат, но узкий список категорий и кандидатов приводил к повторяющимся идеям. Пользователь хочет открывать другие подходящие варианты и видеть расходы. Полного актуального каталога цен по всем заведениям нет; ключ OpenAI имеет ограниченный баланс, инфраструктурный бюджет — ноль.

## Решение

- Расширить городской поиск до категорий, представленных в снимке OSM, включая активный отдых, еду, культуру, исторические места и ночную жизнь. При составном запросе сохранять несколько интересов, а для модели давать кандидатов из разных подходящих категорий. Источником координат и идентификаторов остаётся OSM; ограниченный Overpass дополняет снимок при нехватке мест и запросе на актуальное или конкретное заведение.
- OpenAI интерпретирует запрос и выбирает только найденные идентификаторы. Сервер проверяет их и собирает до трёх вариантов маршрута без общих остановок, с учётом времени и способа передвижения. Кнопка «Ещё идеи» передаёт недавно показанные OSM ID, чтобы сервер исключил их при следующем подборе. Исключение действует в текущей сессии, а не создаёт новые исходные места.
- После выбора остановок отдельный веб-поиск OpenAI проверяет опубликованные цены максимум для шести выбранных потенциально платных мест за запрос. Цена принимается лишь при совпадении места и, если указан, адреса, наличии суммы в тенге и подходящего контекста в источнике. Ответ содержит тип суммы, дату проверки и кликабельную ссылку. Неоднозначная или неподтверждённая цена остаётся неизвестной. Положительный результат кешируется на шесть часов, отсутствие результата — на 30 минут.
- При бюджете на человека варианты с опубликованной ценой билета или средним чеком выше бюджета ставятся ниже. Цена входа, среднего чека или отдельной позиции не складывается в «стоимость маршрута» и не доказывает соответствие бюджету. Часы, наличие мест, мероприятия и дорожные расходы по-прежнему требуют отдельной проверки.
- Сохраняются один Worker и существующая защита запроса. Дополнительный поиск расходует баланс OpenAI; кеш и ограничение частоты уменьшают число повторений, но не заменяют лимит расходов проекта OpenAI.

## Отложено

Не заявлять поиск всех заведений и цен города. Снимок OSM неполон, публичный Overpass может быть недоступен, а открытых цен для многих мест нет. Дополнительный независимый каталог POI можно подключать после проверки лицензии, качества координат и стоимости; непроверенные записи не должны превращаться в остановки маршрута. Платные провайдеры мест и цен не входят в текущую версию с нулевым бюджетом на инфраструктуру.

Для расширения рассмотрен [Overture Maps Places](https://docs.overturemaps.org/guides/places/) — независимый открытый набор мест с ежемесячными выпусками. В `data/research/astana-overture-candidates.json` уже есть 521 машинно отобранный кандидат, но выборочная проверка выявила неверные координаты и категории. Эти записи остаются очередью проверки; высокая оценка confidence сама по себе не подтверждает адрес и тип места. Для дальнейшего импорта нужны проверка филиала, устранение дублей, отдельные ID и [атрибуция Overture](https://docs.overturemaps.org/attribution/). [Geoapify Places](https://www.geoapify.com/pricing/) можно использовать как более надёжный канал к данным OSM, но он не добавит независимый набор заведений. Подтверждённые закрытия из OSM допускается исключать с документированным источником.

## Следствия

ADR 0004 дополняет ADR 0003: пользователь получает больше подходящих категорий, несколько вариантов и повторный поиск по уже найденной базе. Использование OpenAI расширяется на проверку цен, но модель не может назначить цену самостоятельно. Показанная цена — свидетельство из доступного источника на дату проверки, а не гарантия оплаты на месте.
