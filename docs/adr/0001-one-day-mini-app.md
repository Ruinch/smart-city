# ADR 0001: Первый прототип на одном Worker и снимке POI

Дата: 2026-10-18

Статус: принято

## Контекст

Telegram Mini App для первой задачи хакатона должен работать за сутки разработки одним человеком без расходов на инфраструктуру. Для демонстрации важны воспроизводимый сбор мест, точные рекомендации и работающий сценарий на телефоне.

## Решение

- Один Cloudflare Worker обслуживает статический интерфейс, `/api/recommend` и минимальный webhook бота.
- Повторяемый скрипт собирает POI из OpenStreetMap через Overpass. Нормализованный снимок данных входит в сборку приложения.
- Поиск и жёсткие ограничения выполняются сервером. Импортёр создаёт краткие описания из тегов и координат OSM с указанием происхождения. OpenAI получает только отобранные записи, помогает выбрать 1–3 места и может предложить короткую идею действия. Сервер проверяет идентификаторы и идею, сам формирует факты, оценки и ссылки. Сгенерированная идея отделена от фактов о месте.
- В первой версии нет пользовательской базы данных. Геолокация используется для текущего запроса и не сохраняется.
- В интерфейсе есть запасной выбор ориентира при отказе в геолокации. Маршрут открывается во внешней карте.

## Следствия

Каталог обновляется запуском скрипта и новым развёртыванием. Первое покрытие ограничено пилотной зоной вокруг Байтерека. Неполные часы работы, доступность и условия для детей явно обозначаются как неизвестные. При недоступности OpenAI остаётся подбор с шаблонными объяснениями.

Векторная база, встроенная карта, события в реальном времени и многоостановочные маршруты откладываются до проверки основного сценария.
