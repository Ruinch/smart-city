# ADR 0010: Независимые источники заведений с проверкой происхождения

Дата: 2026-10-20
Статус: принято

## Контекст

Снимок OpenStreetMap по Астане и точечный Overpass дают реальные идентификаторы и координаты, но не покрывают все кафе, клубы и другие заведения. «Ещё идеи» лишь перебирает доступных кандидатов. Пользователю нужны более разнообразные и нишевые места; бюджет проекта не позволяет считать платный каталог постоянной бесплатной инфраструктурой. Машинная очередь Overture Maps содержит 521 запись, но выборочная проверка нашла ошибки координат и категорий. Добавление всех этих записей ухудшило бы релевантность и доверие к маршрутам.

## Решение

- Оставить городской снимок OSM и ограниченный Overpass базовым поиском. OpenAI распознаёт интересы и выбирает только идентификаторы, уже найденные сервером; модель не создаёт названия или координаты заведений. При недоступности дополнительного источника маршрут всё ещё может строиться по OSM.
- Использовать [Overture Maps Places](https://docs.overturemaps.org/guides/places/) как независимую открытую очередь возможных мест. Периодическое обновление исходной выборки не даёт автоматического права включать записи в маршруты. Импорт допускает только отобранные записи внутри Астаны: `confidence ≥ 0,8`, совпадение нормализованной улицы и номера дома с независимой адресной записью OSM в пределах 150 м либо отдельное официальное свидетельство о филиале, проверенная категория и происхождение, отсутствие очевидного дубля. Название и тип заведения при адресной сверке по-прежнему происходят из Overture: она **не доказывает существование или текущую работу конкретного филиала**. Исходный GERS ID и ссылка на Overture сохраняются отдельно от OSM ID; адресная запись OSM также сохраняет свою ссылку и атрибуцию ODbL. `confidence` помогает отбору, но [не подтверждает точность остальных атрибутов или работу заведения](https://docs.overturemaps.org/guides/places/#confidence-score). Непрошедшие проверку записи остаются в `data/research/astana-overture-candidates.json` и не участвуют в маршрутах.
- Подготовить необязательный адаптер живого [2ГИС Places API](https://docs.2gis.com/en/api/search/places/overview), но не включать его в опубликованном приложении, пока не подтверждено, что применимые условия ключа разрешают показывать результаты на существующей карте OSM. Документация API описывает поиск организаций, однако доступные [условия Platform Manager](https://law.2gis.ru/en/platform-manager) не дают однозначного разрешения на такое совместное использование. После разрешения адаптер можно включить только одновременно серверным секретом `TWO_GIS_API_KEY` и флагом `TWO_GIS_ENABLED=true`: сервер отправляет готовую поисковую категорию и центр области, округлённый до `0,01°`; полный текст пожелания, точные координаты и данные Telegram туда не передаются. Ответ ограничивается Астаной, проверяется на пригодность координат и типа объекта, сопоставляется с уже найденными местами и получает собственный ID, ссылку на карточку и видимый источник «2ГИС». Ключ остаётся только в Worker; ответы не сохраняются как городской снимок и не кешируются приложением.
- Для каждого источника указывать происхождение прямо у остановки. Карта OSM продолжает иметь [атрибуцию OSM](https://www.openstreetmap.org/copyright); у заведений из Overture также указывать [атрибуцию Overture и вклад соответствующего поставщика](https://docs.overturemaps.org/attribution/), у результатов 2ГИС — 2ГИС и ссылку на карточку. Система устраняет очевидные дубли по названию и близости, не превращает независимые записи в вымышленные OSM ID и не выдаёт разные каталоги за подтверждение каждого свойства места.
- Данные о цене, часах, доступности и событиях остаются неизвестными, если нет отдельного пригодного свидетельства. Сам факт наличия карточки 2ГИС или высокого `confidence` Overture не означает «открыто сейчас» или «подходит под бюджет». Строгий фильтр для коляски по ADR 0009 по-прежнему пропускает только OSM места с `wheelchair=yes`; записи 2ГИС и Overture не получают эту отметку по догадке.

## Стоимость и границы

[Бесплатный демо-ключ 2ГИС](https://docs.2gis.com/en/platform-manager/subscription/keys) создаётся один раз и действует месяц; опубликованный [лимит Places API — 1000 успешных запросов за демо-период](https://docs.2gis.com/en/platform-manager/subscription/pricing). Это полезно для прототипа и демо лишь при допустимых условиях использования, но не является бессрочной бесплатной услугой. Для продолжения живого поиска после срока или лимита нужна платная подписка либо другой разрешённый источник; приложение должно сохранять путь через OSM/Overpass при отсутствии ключа или ответа. Открытые данные Overture не требуют запросов к платному API во время построения маршрута, но требуют проверки качества и атрибуции каждого использованного источника.

## Следствия

ADR 0010 расширяет решения ADR 0003–0004 и 0008, где городской источник описывался как только OSM. Ссылки и ID каждого каталога сохраняют разное происхождение; поиск становится шире без обещания «всех существующих мест» или актуальности каждого филиала. Новые маршруты должны пройти проверку на совпадение адреса и координат, дубли, язык ответа и отсутствие выдуманных цен, часов и доступности. Приватность нового запроса описана на странице «О данных».
