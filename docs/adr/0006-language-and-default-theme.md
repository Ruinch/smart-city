# ADR 0006: Язык советов и светлая тема по умолчанию

Дата: 2026-10-19  
Статус: принято

## Контекст

В задании хакатона есть дополнительная цель «Мультиязычность (советы на языке пользователя)». Конкретные языки не названы. Интерфейс Mini App и серверные описания маршрута до этого были преимущественно русскими. Telegram может передавать тёмную тему, но пользователь попросил открывать приложение в светлой.

## Решение

- Поддерживать русский (`ru`), казахский (`kk`) и английский (`en`). При первом открытии выбирать поддерживаемый язык Telegram, затем браузера; если они не подходят — русский. Пользователь может явно переключить язык; выбор хранится локально в браузере. Светлая тема используется при открытии независимо от темы Telegram.
- Отправлять выбранный язык в `/api/recommend` как `request.language` и в заголовке `Accept-Language` для ошибок, возникающих до чтения тела запроса. Язык совета определяется этим параметром, а не письмом, которым пользователь сформулировал пожелание. Сервер проверяет код языка и для старых клиентов без параметра использует русский.
- Задавать светлые цвета шапки, фона и нижней панели Telegram через доступные методы Mini App, если версия клиента их поддерживает.
- Локализовать интерфейс, карту, состояния загрузки и ошибки, названия категорий, объяснения остановок, действия, предупреждения о неизвестных данных, варианты маршрута и страницу «О данных». Исходное имя конкретного места сохраняется, если у OSM нет подходящего языкового варианта; координаты, цены, ссылки и проверяемые факты не переводятся и не придумываются.
- Модель продолжает выбирать только проверенные идентификаторы мест. Нужный язык текста обеспечивает сервер: шаблоны, проверки и запасной путь работают и при недоступности OpenAI. Языковая настройка не снижает требования к источникам и обозначению неопределённости из ADR 0003 и 0004.

## Следствия

Любой новый пользовательский текст в интерфейсе и ответе сервера должен появляться на всех трёх языках. Переключение языка для уже готового маршрута требует повторного запроса, чтобы перевести серверные объяснения без несоответствия источникам. Название места на исходном языке не считается ошибкой локализации.
