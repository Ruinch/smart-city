# ADR 0002: Карта и поездки из Астаны

Дата: 2026-10-19

Статус: принято

## Контекст

После пилотной прогулки вокруг Бәйтерека пользователь запросил интерактивную карту, параметры бюджета и транспорта, а также идеи поездок за город из Астаны. Городские рекомендации пока опираются на пилотный каталог вокруг Бәйтерека; это не полный каталог Астаны.

## Решение

- Сохранить один Cloudflare Worker и снимок OpenStreetMap для пилотной зоны. Отдельный небольшой каталог хранит загородные места, доступные как идеи поездок из Астаны. Публичный `/api/catalog` отдаёт координаты городских и загородных точек для карты, а `/api/recommend` подбирает варианты после проверки запуска из Telegram.
- Пользователь выбирает прогулку по городу либо поездку за город, время, способ передвижения и предельный бюджет. Городской подбор ограничен пилотной зоной. Для поездок старт — в Астане или рядом с ней; центр города используется без геолокации.
- Время пешком в пилотной зоне оценивается по прямому расстоянию с коэффициентом, без обратного пути. Время городской дороги на автомобиле или общественном транспорте не вычисляется без маршрутизатора. Для загородной поездки время туда и обратно рассчитывается только из сохранённой оценки одной стороны с источником; общественный транспорт предлагается только при наличии такой оценки.
- Отсутствующая стоимость или время дороги не считаются нулём и не показываются как подходящие под бюджет или время. Загородные варианты по умолчанию требуют запаса от 8 часов; подтверждённая источником категория «полдня» снижает порог до 4 часов. Это фильтр планирования, а не точное время дороги.
- Карта показывает точки с видимой атрибуцией OpenStreetMap. Внешний маршрут открывается в картографическом сервисе. Геолокация не сохраняется. Серверный отбор и защита от выдуманных ИИ фактов сохраняются из ADR 0001.

## Следствия

Это решение заменяет пункт ADR 0001 об отложенной встроенной карте и добавляет загородный каталог. Ограничение городского покрытия пилотной зоной действует. Каталоги обновляются отдельным запуском и развёртыванием. Дорожная обстановка, погода, режим работы и точная цена не отслеживаются в реальном времени; отсутствие данных явно показывается пользователю.
