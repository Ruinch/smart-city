# Дополнительные кандидаты мест

`astana-overture-candidates.json` — экспериментальная машинная выборка Overture Maps Places по Астане от 19 октября 2026 года. Записи содержат исходный GERS ID, поставщика, лицензию и ссылку на Overture Explorer. Файл имеет `candidateOnly: true` и **не используется для маршрутов**.

Выборочная проверка исходных 607 точек обнаружила неверно расположенные объекты и ошибочные категории. После фильтрации осталось 521 предложение; это всё ещё кандидаты, которым нужна независимая проверка по OSM или сайту места перед публикацией. Не выдавайте записи Overture за объекты OSM и не создавайте фиктивные OSM ID.
