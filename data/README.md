# Данные мест Астаны

Основной городской индекс `astana-dynamic-fallback.json` создаётся автоматически из ежедневной выгрузки Казахстана от [Geofabrik](https://download.geofabrik.de/asia/kazakhstan.html), построенной на OpenStreetMap. Граница города взята из [OSM relation 3087156](https://www.openstreetmap.org/relation/3087156). Скрипт `scripts/build-astana-fallback.py` выбирает именованные объекты подходящих категорий внутри этой границы, сохраняет OSM type/ID, координаты, полезные теги, ссылку на запись и дату данных. Фактическую работу заведений этот снимок не подтверждает. Ориентиры для старта хранятся отдельно в `landmarks`.

Для обновления нужен Python с `osmium` (`pip install osmium`). Запустите:

```powershell
python scripts/build-astana-fallback.py
```

Можно передать уже скачанный PBF: `python scripts/build-astana-fallback.py --input C:\path\to\kazakhstan.osm.pbf`. Большой исходный PBF не хранится в репозитории. Городской индекс не ограничен вручную выбранными 27 точками: поиск по нему выполняется под текущий запрос, а Overpass может дополнить недостающие данные. При этом OSM не содержит буквально все существующие заведения и может отставать от реальности.

`visitMinutes` — допуск для планирования по категории, а не подтверждённые часы работы, время в пути, цена, доступность или рекомендация для детей. Отсутствующий тег означает «неизвестно». Для OSM way координата может быть геометрическим центром здания или территории, а не входом. Приложение обязано показывать источник и эти ограничения. Данные карты и мест: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL.

`pois.json` — фиксированный набор первого пилота у Бәйтерека. Он используется в `src/worker/recommend.test.ts` для регрессионной проверки короткой прогулки и проверяется командой `npm run data:check` вместе с каталогом поездок. Рабочий поиск по городу этот набор не загружает. Устаревшие сборщик пилота и исходный ответ Overpass удалены; при необходимости их можно восстановить из истории Git.

`astana-boundary.json` хранит границу в формате GeoJSON. Один и тот же файл используется сервером и скриптом обновления городского индекса.

`astana-overture-verified.json` — отдельная небольшая выборка [Overture Maps Places](https://docs.overturemaps.org/guides/places/) со сверкой адреса и координат по независимому адресному источнику. Серверный импортёр дополнительно проверяет свидетельство, происхождение, допустимую лицензию, категорию, расположение внутри Астаны и повторы уже известных мест. Адресная сверка не подтверждает название или текущую работу филиала: эти сведения остаются данными Overture. Непроверенная машинная очередь в [`research/`](research/README.md) не загружается в маршруты. Ни данные Overture, ни совпадение адреса не подтверждают часы, цены или доступность для коляски; исходный GERS ID и [атрибуция](https://docs.overturemaps.org/attribution/) сохраняются отдельно от OSM.

## Поездки из Астаны

`astana-trips.json` — отдельный небольшой набор поездок за город. Точки привязаны к конкретным OSM объектам: [музей АЛЖИР](https://www.openstreetmap.org/way/1465089835), [смотровая Болектау](https://www.openstreetmap.org/node/6522625814) и [музей Ботай](https://www.openstreetmap.org/way/1116434315). Время посещения и широкие категории длительности — планировочные оценки. Точные дорога, топливо, билеты, часы работы и доступность не подтверждаются без отдельного источника. Приложение не считает неизвестную цену нулём и не обещает попадания в бюджет или срок.

Эти поездки не подмешиваются в городской запрос о кафе, клубе или прогулке. Для самостоятельно организованной поездки нужно проверить дорогу и условия перед выездом.
