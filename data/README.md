# Astana pilot POI catalog

`pois.json` is a small, reproducible OpenStreetMap snapshot for a 2.5 km radius around Бәйтерек. Generate it with:

```sh
node scripts/collect-poi.mjs --audit
node scripts/collect-poi.mjs
node scripts/collect-poi.mjs --input data/raw/overpass-bayterek.json
npm run data:check
```

The importer requests named tourism, heritage, park, cafe, playground, and cultural objects from Overpass, then excludes private, disused, and incomplete records. The small pilot selection keeps only two recognizable destinations among OSM's generic `tourism=attraction` records; this avoids listing every ride and small statue as a separate walk stop. It keeps each object's OSM type, ID, tags, source URL, import time, and Overpass data timestamp. A successful live import saves the raw response to `data/raw/overpass-bayterek.json`, which can reproduce the selection offline. A failed request or fewer than 15 usable POIs leaves the existing catalog untouched. `--audit` prints a summary without writing.

The pilot also keeps OSM way `230358854`, named `Сквер` and tagged `leisure=park`, as a short park stop near Бәйтерек. Its 20-minute visit allowance is a planning estimate chosen for the 30-minute outdoor demo. OSM does not confirm the entrance, access conditions, or the actual walking route; the UI must keep these unknowns visible.

`visitMinutes` is a planning allowance by category, **not** a verified opening time, live availability, admission price, accessibility claim, or recommendation for children. OSM tags such as `opening_hours`, `fee`, and `wheelchair` are retained verbatim; missing tags mean unknown. For OSM ways and relations, Overpass `out center` returns the middle of the bounding box, so the displayed coordinate may differ from the entrance.

Each POI has a short Russian `description` generated by the importer from its OSM category and approximate straight-line distance from Бәйтерек based on OSM coordinates. When explicit OSM tags provide a narrower type, indoor tag, or address, the description includes that detail and `descriptionSource` is `osm_tags`; otherwise it is `category_template`. These are deliberately neutral catalog summaries, not verified venue descriptions or walking distances. None of the current 27 records has an OSM `description` tag, so the importer does not invent exhibits, amenities, prices, atmosphere, or current availability. The same descriptions can be regenerated from the saved raw Overpass snapshot.
