# Astana pilot POI catalog

`pois.json` is a small, reproducible OpenStreetMap snapshot for a 2.5 km radius around Бәйтерек. Generate it with:

```sh
node scripts/collect-poi.mjs --audit
node scripts/collect-poi.mjs
node scripts/collect-poi.mjs --input data/raw/overpass-bayterek.json
npm run data:check
```

The importer requests named tourism, heritage, park, cafe, playground, and cultural objects from Overpass, then excludes private, disused, and incomplete records. The small pilot selection keeps only two recognizable destinations among OSM's generic `tourism=attraction` records; this avoids listing every ride and small statue as a separate walk stop. It keeps each object's OSM type, ID, tags, source URL, import time, and Overpass data timestamp. A successful live import saves the raw response to `data/raw/overpass-bayterek.json`, which can reproduce the selection offline. A failed request or fewer than 15 usable POIs leaves the existing catalog untouched. `--audit` prints a summary without writing.

The pilot also keeps OSM way `230358854`, named `Сквер` and tagged `leisure=park`, as a short park stop near Бәйтерек. Its 20-minute visit allowance is a planning estimate chosen for the 30-minute outdoor demo. OSM does not confirm the entrance, access conditions, or the actual walking route; the UI must keep these unknowns visible.

`visitMinutes` is a planning allowance by category, **not** a verified opening time, live availability, admission price, accessibility claim, or recommendation for children. OSM tags such as `opening_hours`, `fee`, and `wheelchair` are retained verbatim; missing tags mean unknown. For OSM ways and relations, Overpass `out center` returns the middle of the bounding box, so the displayed coordinate may differ from the entrance.

Each POI has a short Russian `description` generated by the importer from its OSM category and approximate straight-line distance from Бәйтерек based on OSM coordinates. When explicit OSM tags provide a narrower type, indoor tag, or address, the description includes that detail and `descriptionSource` is `osm_tags`; otherwise it is `category_template`. These are deliberately neutral catalog summaries, not verified venue descriptions or walking distances. None of the current 27 records has an OSM `description` tag, so the importer does not invent exhibits, amenities, prices, atmosphere, or current availability. The same descriptions can be regenerated from the saved raw Overpass snapshot.

Map and place data: © OpenStreetMap contributors, [ODbL](https://www.openstreetmap.org/copyright). Display attribution in the app wherever these places or a map based on OSM are shown. Public Overpass is a shared service: refresh this server-side catalog sparingly and serve users from the saved file, rather than querying Overpass for each request.

## Trips from Astana

`astana-trips.json` is a small, manually reviewed catalog of destinations outside Astana. It uses the existing city pilot as the only origin. Each pin has an exact OSM object ID and coordinate, checked through OSM Nominatim on 2026-10-19. The three initial targets are the [АЛЖИР museum](https://www.openstreetmap.org/way/1465089835), [Болектау viewpoint](https://www.openstreetmap.org/node/6522625814), and [Ботай museum](https://www.openstreetmap.org/way/1116434315). The map and route links point to these specific objects rather than a national park polygon centre.

An official [government account](https://kgd.gov.kz/ru/news/news/segodnya-sotrudniki-komiteta-gosudarstvennyh-dohodov-mf-rk-kollektivno-posetili-muzeyno) places АЛЖИР about 37 km from Astana along the Korgalzhyn road. [Visit Astana](https://www.visitastana.kz/ru/weekend-tours/ekskursiya-v-muzey-alzhir-tayny-malinovki/) describes a 3–3.5-hour organised excursion, so `half_day` is only a broad planning class. [Visit Astana](https://www.visitastana.kz/ru/weekend-tours/odnodnevnyy-tur-v-burabay/) offers a one-day Burabay tour, supporting `full_day` for the Болектау option. [Kazakhstan Travel](https://kazakhstan.travel/ru/parks/burabay) describes Burabay as about 260 km from Astana, but that distance does not resolve the exact route to Болектау, so the catalog does not attach it as `roadKmApprox`. [Kazakhstan Travel](https://www.kazakhstan.travel/ru/attractions/1) confirms the Ботай museum in the Burabay area. Its exact road distance remains unknown.

`visitMinutes` and broad duration classes are planning allowances, not current road ETAs. No current one-way driving or public transport time, admission, fuel cost, or full trip budget is verified for these self-guided trips; the catalog leaves those fields absent. An organised tour price is not interchangeable with a self-guided trip budget. Road conditions, hours, fees, and access must be checked before departure. The Korgalzhyn nature reserve is deliberately absent: its OSM polygon centre is not a reliable routable visitor entrance, and its access conditions need separate verification.

The `setting` field records whether the main visit is indoors or outdoors and keeps a separate source link. The [АЛЖИР museum](https://museum-alzhir.kz/ru/istoriya-muzeya) describes indoor exhibition floors; the Болектау OSM record is a viewpoint; [Kazakhstan Travel](https://www.kazakhstan.travel/ru/attractions/1) explicitly calls the Ботай museum open air. A museum category alone does not establish an indoor visit. The OSM record for АЛЖИР also says `fee=yes`, so a zero-budget request excludes it even though the complete trip price remains unknown.
