# рядом.

**Telegram Mini App, которая помогает решить, куда пойти в Астане.** Опишите желание своими словами — приложение подберёт места, объяснит выбор и соберёт маршрут с учётом времени, точки старта и компании.

[Открыть бота](https://t.me/smart_city_ryadombot) · [Посмотреть интерфейс](https://smart-city-astana-walk.menplexroma.workers.dev/) · [Сценарии демо](docs/jury-demo.md)

Подбор маршрутов работает при открытии через Telegram. По обычной ссылке можно посмотреть интерфейс, но для запроса нужен подтверждённый запуск Mini App.

## Что умеет приложение

- **Подбирать по желанию.** Например: «Тихое кафе, чтобы почитать», «Хочу танцевать» или «Погулять с друзьями у воды». Кнопка «Удиви меня» предлагает одно место без обязательного текста.
- **Учитывать условия.** От 30 минут до 24 часов, пешком / транспорт / машина, бюджет в тенге на человека, компания от 1 до 12 человек.
- **Начинать от нужной точки.** Геопозиция, ручной выбор на карте или центр Астаны. Можно указать примерное направление движения.
- **Давать выбор.** До трёх городских маршрутов с одной–тремя остановками. У каждого места — короткое «почему», идея занятия, время посещения и источники.
- **Менять одну остановку.** Причины: далеко, дорого, уже был или хочется другое. Остальные точки сохраняются. «Ещё идеи» исключает недавно показанные места.
- **Предлагать дополнительные сценарии.** Короткие переходы, неспешная прогулка, фильтр доступности для коляски и микроприключение с небольшими заданиями.
- **Показывать события и поездки.** Датированные события из доступных афиш и отдельный небольшой каталог поездок из Астаны. У событий указаны источник и время проверки.
- **Работать на трёх языках.** Русский, казахский и английский; рекомендации формируются на выбранном языке.

### Как устроен интерфейс

Сначала пользователь вводит желание, выбирает старт и время. Дополнительные условия открываются в отдельной панели. После подбора можно прочитать варианты и открыть выбранный маршрут на карте.

На карте — нумерованные остановки и выдвижная панель маршрута: её можно свернуть, раскрыть наполовину или поднять выше. Векторная подложка MapLibre + OpenFreeMap сохраняет чёткость при увеличении; при недоступности WebGL2 или сбое векторной подложки используется растровая карта OpenStreetMap. Интерфейс поддерживает светлую тему, плавные переходы и системное уменьшение анимаций.

## Как находятся места

1. **Запрос.** Cloudflare Worker проверяет подпись Telegram и частоту обращений. OpenAI помогает определить намерение и подходящие категории.
2. **Кандидаты.** Сервер ищет в городском снимке OpenStreetMap, при нехватке данных обращается к Overpass и добавляет допустимые записи Overture с независимо сверенными адресом и координатами.
3. **Маршрут.** Модель выбирает из найденных кандидатов. Сервер проверяет идентификаторы и ограничения: сгенерированное название не становится новым местом на карте.
4. **Подробности.** Для выбранных остановок сервер проверяет доступные страницы заведений и использует ограниченный веб-поиск OpenAI для сведений и цен. Принятые сведения показываются со ссылкой на источник.
5. **Результат.** Пользователь получает остановки с объяснениями и схемой пути; события показываются отдельно. Настоящие дорожные указания открываются во внешней карте.

Адаптер **2ГИС Places** подготовлен, но по умолчанию выключен. Для включения нужны ключ и подтверждение, что условия API разрешают показ результатов на используемой карте. Ключ для OpenFreeMap не нужен.

Источники, происхождение данных и обновление каталогов описаны в [data/README.md](data/README.md).

## Локальный запуск

Нужны **Node.js 24+ и npm**. Для полноценного подбора также нужны Telegram-бот и ключ OpenAI. Python нужен только для обновления городского снимка, а готовые данные уже включены в репозиторий.

### 1. Установить зависимости

```powershell
npm ci
```

При первом запуске создайте `.dev.vars` из шаблона. Следующая команда сохраняет существующий файл:

```powershell
if (-not (Test-Path .dev.vars)) {
  Copy-Item .dev.vars.example .dev.vars
}
```

Заполните значения локально:

| Переменная | Назначение |
| --- | --- |
| `OPENAI_API_KEY` | Разбор запроса, выбор мест и исследование сведений через OpenAI |
| `TELEGRAM_BOT_TOKEN` | Токен от BotFather; проверка запуска Mini App и работа бота |
| `TELEGRAM_WEBHOOK_SECRET` | Случайная строка для проверки запросов webhook; латинские буквы, цифры, `_` и `-` |
| `MINI_APP_URL` | Публичный HTTPS-адрес приложения после публикации |

`.dev.vars` исключён из Git. Не помещайте ключи в клиентский код или README. Скрипт публикации секретов требует все четыре значения. Без OpenAI сервер может использовать резервные правила подбора, но AI-возможности будут недоступны.

### 2. Запустить приложение вместе с сервером

```powershell
npm run build
npm run worker:dev
```

Локальный адрес по умолчанию: `http://127.0.0.1:8787`. После изменений интерфейса повторите сборку: Worker отдаёт файлы из `dist`.

Для быстрой работы **только над интерфейсом** используйте `npm run dev` (обычно порт 5173). Эта команда не запускает серверные API; прокси к Worker не настроен. `npm run preview` тоже показывает только интерфейс.

Локальный API сохраняет проверку Telegram. Для полноценного прохождения пользовательского сценария используйте опубликованную Mini App через бота; для проверки сервера локально есть отдельная команда ниже.

### 3. Проверить изменения

```powershell
npm test
npm run build
npm run data:check
```

При работающем локальном Worker можно проверить четыре сценария с подписанным тестовым запросом:

```powershell
npm run smoke:local
```

Эта команда обращается к реальным внешним сервисам и **расходует баланс OpenAI**. Чтобы выполнить только один сценарий:

```powershell
npm run smoke:local -- http://127.0.0.1:8787 coffee-reading
```

Сценарии проверки интерфейса, ограничения браузерной проверки и результаты прогонов — в [docs/TESTING.md](docs/TESTING.md).

## Публикация

Рабочий проект размещён в Cloudflare Worker `smart-city-astana-walk`. Для него настроена публикация из `main` через подключённый GitHub-репозиторий.

Для первого ручного развёртывания в своём аккаунте:

```powershell
npx wrangler login
npm run deploy
```

Затем передайте публичный HTTPS-адрес созданного Worker:

```powershell
npm run secrets:publish -- https://your-worker.your-subdomain.workers.dev
npm run bot:configure -- https://your-worker.your-subdomain.workers.dev
```

- `secrets:publish` переносит четыре основные переменные из локального `.dev.vars` в Cloudflare.
- `bot:configure` настраивает webhook, команды `/start` и `/help`, кнопку открытия Mini App.
- Если адрес приложения и токен не менялись, повторно настраивать бота после каждой публикации не нужно.
- Для собственного бота замените также ссылки на `@smart_city_ryadombot` в клиентском коде и публичных материалах. Для другого имени Worker измените `wrangler.jsonc`.
- Необязательные `TWO_GIS_API_KEY` и `TWO_GIS_ENABLED=true` добавляются в Cloudflare отдельно: `secrets:publish` их не переносит.

`GET /api/health` показывает состояние приложения и размеры каталогов. Он не проверяет работоспособность ключей Telegram и OpenAI.

## Что важно знать о точности

- **География:** городские маршруты — только Астана. Загородные поездки берутся из отдельного ограниченного каталога.
- **Полнота:** приложение не знает все заведения и не гарантирует найти цену для каждого. Наличие записи в каталоге не доказывает, что место сейчас работает.
- **Время и дорога:** линии между остановками — схема, а не путь по улицам. Пешее время приблизительное; время на машине и транспорте остаётся неизвестным без дорожного источника.
- **Бюджет:** неизвестная цена не означает бесплатность. Цена билета, средний чек или цена одной позиции не равны полной стоимости маршрута. Бюджет `0 ₸` исключает коммерческие категории, но не подтверждает бесплатность остальных мест.
- **Доступность:** строгий фильтр использует явный `wheelchair=yes` в OSM. Он не проверяет тротуары, бордюры и весь путь между остановками; данных может оказаться недостаточно.
- **Актуальность:** время проверки страницы не гарантирует актуальность меню, расписания, билетов или условий входа. Неизвестные свойства не подменяются уверенными обещаниями.
- **Приватность:** собственной базы истории запросов и точных координат нет. Внешние сервисы получают данные, необходимые для своей работы; подробности — в [политике данных](public/privacy.html).
- **Расходы:** OpenAI и веб-поиск расходуют баланс ключа. Ограничение частоты запросов не является общим денежным лимитом.

Если Telegram сообщает об устаревшей сессии, полностью закройте Mini App и откройте её через бота заново.

## Структура проекта

```text
src/client/       Интерфейс, карта, панели и анимации
src/worker/       API, Telegram, подбор, проверка источников и цен
src/shared/       Общие типы и география Астаны
data/             Каталоги, границы, исключения и сведения об источниках
scripts/          Публикация, настройка бота, обновление данных и проверки
public/           Публичная информация о данных
docs/             Архитектурные решения, сценарии демо и проверки
deliverables/     Презентация и архивные материалы первого пилота
```

Рабочие тесты `*.test.ts` находятся рядом с соответствующими модулями и запускаются через `npm test`. `data/pois.json` сохранён как фиксированный набор для регрессионной проверки первого сценария; текущий поиск по городу использует другой, автоматически собранный индекс.
