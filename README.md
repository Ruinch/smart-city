# Рядом — прогулки по Астане и поездки из неё

Telegram Mini App для первой задачи хакатона. На карте показаны реальные места в центре Астаны и отдельные направления для поездки из города. Пользователь задаёт время, способ передвижения, бюджет и пожелания, а приложение предлагает до трёх вариантов с источниками. Городской каталог пока ограничен районом Бәйтерека: это пилот, а не полный охват Астаны.

## Как работает

1. `data/pois.json` содержит городской каталог из OpenStreetMap. `data/astana-trips.json` содержит небольшой набор загородных направлений с источниками. Публичный `/api/catalog` отдаёт координаты для интерактивной карты.
2. Mini App передаёт подписанные данные запуска Telegram и выбранные условия на `/api/recommend`. Worker проверяет подпись и подбирает места по доступным данным. Неизвестные цены и время дороги не считаются нулём и не подтверждают попадание в бюджет или время.
3. Для городских пеших прогулок модель OpenAI может выбрать до трёх мест из короткого списка и предложить идею действия. Сервер проверяет выбор и отделяет идею от фактов. Если модель недоступна, подбор продолжает работать по правилам. Загородные идеи не зависят от модели.

Интерфейс и API размещаются вместе в Cloudflare Worker. История запросов и координаты не сохраняются в собственной базе. [Как используются данные](public/privacy.html).

## Подготовка

Нужны Node.js 24+, Telegram-бот от [@BotFather](https://t.me/BotFather), ключ проекта OpenAI и аккаунт Cloudflare.

```powershell
npm ci
npm run data:check
npm test
npm run build
```

Локальный `.dev.vars` содержит `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `MINI_APP_URL`. Он исключён из Git. Шаблон — [.dev.vars.example](.dev.vars.example). Ключи нельзя публиковать или добавлять в клиентский код.

Для просмотра интерфейса в обычном браузере: `npm run dev`. Отправлять запросы на подбор может только Mini App, открытый через Telegram с действительной подписью запуска. Для локальной разработки Worker: `npm run build`, затем `npm run worker:dev`.

## Публикация

1. Создайте бота в BotFather командой `/newbot`; сохраните его токен и ключ OpenAI в `.dev.vars`.
2. Авторизуйте Wrangler: `npx wrangler login`.
3. Выполните `npm run deploy` и сохраните адрес `https://…workers.dev`.
4. Выполните `npm run secrets:publish -- https://…workers.dev`. Скрипт передаёт четыре значения из `.dev.vars` в секреты Worker без вывода их содержимого.
5. Выполните `npm run bot:configure -- https://…workers.dev`. Скрипт задаёт webhook, команду `/start` и кнопку Mini App в меню бота.
6. На телефоне откройте бота, отправьте `/start`, нажмите кнопку и проверьте карту и подбор. `/api/health` должен вернуть `status: ok` и размер каталога.

После обновления каталогов повторите `npm run deploy`.

## Данные и ограничения

- Городские места покрывают район Бәйтерека, а не всю Астану. Каждый POI имеет OSM ID и ссылку на исходную запись. Описания основаны на категории и тегах OSM, а не на проверке объекта на месте. Данные: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL.
- Время пешком — оценка по прямой с коэффициентом обхода, без обратного пути. Для машины и общественного транспорта городское время дороги не вычисляется без маршрутизатора.
- Для загородной поездки время дороги и расходы указываются только при наличии источника. Если данных нет, соответствие времени и бюджету остаётся неподтверждённым. Это идеи для отдельной поездки, а не готовый маршрут с гарантированным расписанием.
- Интерактивная карта загружает видимые фрагменты с OpenStreetMap. Внешний маршрут открывается в Google Maps; при его открытии начальная и конечная точки передаются этому сервису. Список точек остаётся доступен без карты.
- Часы работы, доступность, дорожная обстановка, погода и удобства для детей не подтверждаются в реальном времени. Координата OSM way/relation может быть центром объекта, а не входом.

## Проверка перед защитой

- Запуск из `/start` и кнопки меню на телефоне.
- Переключение «В городе / За городом», карта с маркерами и списком точек.
- Выбор времени, транспорта, бюджета, пожеланий и отказ в геолокации.
- Несколько запросов, пустая выдача, недоступный OpenAI и неизвестные цены или дорога.
- Ссылки на источники и маршрут, атрибуция OSM, страница «О данных».
