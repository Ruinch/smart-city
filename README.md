# Рядом — маршруты по Астане

Telegram Mini App для первой задачи хакатона. Человек описывает, куда хочется пойти, обычными словами: например, «клуб и танцы» или «спокойное кафе, чтобы почитать». Приложение учитывает время, транспорт, число участников и необязательную геопозицию. Бюджет указывается на человека: запрос на 0 ₸ исключает коммерческие категории, а при неизвестной цене приложение не обещает уложиться в указанную сумму. Результат — один маршрут с одной–тремя остановками и картой. Отдельный режим предлагает поездки из Астаны.

## Как работает

1. Mini App передаёт запрос и подписанные Telegram данные в `/api/recommend`. Worker проверяет подпись и ограничивает частоту запросов.
2. OpenAI определяет тему запроса и подходящие категории мест. Сервер ищет кандидатов в автоматически собранной широкой выгрузке OpenStreetMap по Астане. Для уточнения недостающих категорий может использоваться ограниченный запрос к Overpass; его результаты кешируются.
3. OpenAI выбирает из найденных кандидатов порядок остановок. Сервер принимает только известные OSM ID, проверяет координаты и ограничения времени, составляет полный маршрут и ссылки на источники. Для субъективных или меняющихся свойств может выполняться веб-поиск; результат показывается только с кликабельной ссылкой на источник.
4. Карта и POI появляются после построения маршрута. Нумерованные точки соответствуют остановкам. Если нет дорожной геометрии, пунктир обозначает лишь порядок точек; реальный путь открывается во внешней карте.

Загородный режим пока использует отдельные проверяемые направления из `data/astana-trips.json`. У него иные требования ко времени и дороге; он не смешивается с городским поиском клубов, кафе и прогулок.

## Запуск и публикация

Нужны Node.js 24+, Telegram-бот от [@BotFather](https://t.me/BotFather), ключ OpenAI и аккаунт Cloudflare.

```powershell
npm ci
npm run build
npm test
```

Локальный `.dev.vars` содержит `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `MINI_APP_URL`. Он исключён из Git. Шаблон — [.dev.vars.example](.dev.vars.example). Ключи не должны попадать в клиентский код или репозиторий.

Для просмотра интерфейса в браузере: `npm run dev`. Подбор принимает только действительный запуск Mini App через Telegram. Для локальной разработки Worker: `npm run build`, затем `npm run worker:dev`. При работающем локальном Worker команда `npm run smoke:local` проверяет три сценария с тестовой Telegram-подписью; она обращается к OpenAI и расходует небольшую часть баланса ключа.

При первой публикации авторизуйте Wrangler (`npx wrangler login`), выполните `npm run deploy`, затем `npm run secrets:publish -- https://…workers.dev` и `npm run bot:configure -- https://…workers.dev`. Последняя команда задаёт webhook, `/start` и кнопку Mini App. При изменении кода или данных повторите развёртывание; настроенный webhook сохраняется, если адрес Worker не менялся.

## Данные и пределы точности

- Источник городских мест — данные © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL. Городской снимок автоматически извлекается из публикации Geofabrik; подробная запись OSM открывается из каждой остановки. Публичный Overpass может быть перегружен, а сведения OSM неполны; приложение не обещает найти буквально все заведения города.
- Цена, наличие мест для компании, актуальная программа клуба, тишина, часы работы и дорожная обстановка не выводятся из одной только категории OSM. Неподтверждённые свойства показываются как неизвестные. Бюджет задаётся на человека; неизвестная стоимость не означает, что место бесплатное или укладывается в бюджет.
- Время пешком и расстояние между точками — приблизительные расчёты. Пунктир на карте не является уличным маршрутом. Для машины и общественного транспорта точное время дороги не заявляется без дорожного источника.
- Внешняя карта получает координаты старта и остановок, только когда пользователь открывает ссылку маршрута. Технические данные соединения передаются также сервису тайлов при просмотре карты. История запросов и координаты не сохраняются в собственной базе. Подробности — [«О данных»](public/privacy.html).
