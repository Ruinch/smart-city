# Рядом — маршруты по Астане

Telegram Mini App для первой задачи хакатона. Человек описывает, куда хочется пойти, обычными словами: например, «клуб и танцы» или «спокойное кафе, чтобы почитать». Приложение учитывает время, транспорт, число участников и необязательную геопозицию. Бюджет указывается на человека: запрос на 0 ₸ исключает коммерческие категории, а при неизвестной цене приложение не обещает уложиться в указанную сумму. Результат — до трёх разных городских маршрутов с одной–тремя остановками каждый и картой выбранного маршрута. Кнопка «Ещё идеи» ищет другие места по тем же условиям. Отдельный режим предлагает поездки из Астаны.

## Как работает

1. Mini App передаёт запрос и подписанные Telegram данные в `/api/recommend`. Worker проверяет подпись и ограничивает частоту запросов.
2. OpenAI определяет тему запроса и подходящие категории мест. Поиск охватывает категории городского снимка OpenStreetMap: еду и напитки, культуру, природу, ночную жизнь, занятия с друзьями и другие типы мест. Сервер отбирает кандидатов из автоматически собранной выгрузки по Астане, дополняя её ограниченным запросом к Overpass, когда сведений мало или пользователь просит актуальное либо конкретное место. Результаты внешнего поиска кешируются.
3. OpenAI выбирает остановки из сбалансированного по категориям списка кандидатов. Сервер принимает только найденные OSM ID, проверяет координаты и ограничения времени, затем собирает до трёх разных вариантов без повторения остановок. «Ещё идеи» исключает ранее показанные точки в текущей сессии Mini App. Для субъективных или меняющихся свойств может выполняться веб-поиск; утверждение показывается только с кликабельным источником.
4. Для выбранных платных мест сервер может отдельно искать опубликованные цены через веб-поиск OpenAI. Он проверяет соответствие заведения, указанного адреса, суммы в тенге и типа цены содержимому источника. Рядом с подтверждённой ценой показаны источник и дата проверки; иначе стоимость остаётся неизвестной. За один запрос проверяется не более шести выбранных мест. Если опубликованная цена билета или средний чек выше бюджета на человека, такой вариант опускается ниже. Найденная цена входа, среднего чека или одной позиции не равна полной стоимости маршрута.
5. Карта и POI появляются после построения маршрута. Нумерованные точки соответствуют остановкам выбранного варианта. Если нет дорожной геометрии, пунктир обозначает лишь порядок точек; реальный путь открывается во внешней карте.

Загородный режим пока использует отдельные проверяемые направления из `data/astana-trips.json`. У него иные требования ко времени и дороге; он не смешивается с городским поиском клубов, кафе и прогулок.

## Запуск и публикация

Нужны Node.js 24+, Telegram-бот от [@BotFather](https://t.me/BotFather), ключ OpenAI и аккаунт Cloudflare.

```powershell
npm ci
npm run build
npm test
```

Локальный `.dev.vars` содержит `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `MINI_APP_URL`. Он исключён из Git. Шаблон — [.dev.vars.example](.dev.vars.example). Ключи не должны попадать в клиентский код или репозиторий.

Для просмотра интерфейса в браузере: `npm run dev`. Подбор принимает только действительный запуск Mini App через Telegram. Для локальной разработки Worker: `npm run build`, затем `npm run worker:dev`. При работающем локальном Worker команда `npm run smoke:local` проверяет три сценария с тестовой Telegram-подписью; она обращается к OpenAI и расходует небольшую часть баланса ключа.

При первой публикации авторизуйте Wrangler (`npx wrangler login`), выполните `npm run deploy`, затем `npm run secrets:publish -- https://…workers.dev` и `npm run bot:configure -- https://…workers.dev`. Последняя команда задаёт webhook, `/start` и кнопку Mini App. При изменении кода или данных повторите развёртывание; настроенный webhook сохраняется, если адрес Worker не менялся.

## Данные и пределы точности

- Источник городских мест — данные © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL. Городской снимок автоматически извлекается из публикации Geofabrik; подробная запись OSM открывается из каждой остановки. Публичный Overpass может быть перегружен, а сведения OSM неполны; приложение не обещает найти буквально все заведения города.
- Подтверждённые закрытия могут исключаться из подбора отдельно от исходного снимка. Например, [администрация Астаны сообщила о закрытии аквапарка Ailand](https://www.gov.kz/org/astana-nura/press/news/details/1047434?lang=ru), хотя объект сохранился в OSM; запись и источник исключения находятся в `data/astana-place-exclusions.json`.
- Опубликованные цены находятся не для каждого места. Поиск цен ограничен выбранными остановками и доступностью открытых источников; успешные результаты кешируются до шести часов, отсутствие результата — до 30 минут. Цена могла измениться после проверки, а отдельная позиция или вход не покрывают все расходы. Бюджет задаётся на человека; неизвестная стоимость не означает, что место бесплатное или укладывается в бюджет.
- Наличие мест для компании, актуальная программа клуба, тишина, часы работы и дорожная обстановка не выводятся из одной только категории OSM. Неподтверждённые свойства показываются как неизвестные. Снимок OSM и публичный Overpass не гарантируют полный список заведений; «Ещё идеи» может исчерпать доступные подходящие места.
- Время пешком и расстояние между точками — приблизительные расчёты. Пунктир на карте не является уличным маршрутом. Для машины и общественного транспорта точное время дороги не заявляется без дорожного источника.
- Внешняя карта получает координаты старта и остановок, только когда пользователь открывает ссылку маршрута. Технические данные соединения передаются также сервису тайлов при просмотре карты. История запросов и координаты не сохраняются в собственной базе. Подробности — [«О данных»](public/privacy.html).
- Вызовы OpenAI, включая `web_search`, расходуют баланс ключа. Кеш и ограничение частоты уменьшают повторные запросы, но не устанавливают общий дневной предел затрат. Для публичной версии задайте [лимит расходов в проекте OpenAI](https://developers.openai.com/api/docs/guides/spend-limits); стоимость поиска и токенов проверяйте на [странице тарифов OpenAI](https://developers.openai.com/api/docs/pricing).
