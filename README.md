# Рядом — маршруты по Астане

Telegram Mini App для первой задачи хакатона. Человек описывает, куда хочется пойти, обычными словами: например, «клуб и танцы» или «спокойное кафе, чтобы почитать». Приложение учитывает время от 1 до 24 часов, транспорт, число участников, необязательную геопозицию и выбранное на карте примерное направление. Бюджет указывается на человека: запрос на 0 ₸ исключает коммерческие категории, а при неизвестной цене приложение не обещает уложиться в указанную сумму. Результат — до трёх разных городских маршрутов с одной–тремя остановками каждый и картой выбранного маршрута. Кнопка «Ещё идеи» ищет другие места по тем же условиям. Отдельный режим предлагает поездки из Астаны.

Дополнительные добровольные условия помогают искать места с отметкой доступности для коляски в OSM, ограничить приблизительную длину пеших переходов или составить неспешный городской маршрут с максимум двумя остановками и большим временем на каждой. «Микроприключение» добавляет к реальным городским остановкам короткие игровые задания; отметки выполнения хранятся только пока открыта Mini App.

## Как работает

1. Mini App передаёт запрос и подписанные Telegram данные в `/api/recommend`. Worker проверяет подпись и ограничивает частоту запросов.
2. OpenAI определяет тему запроса и до шести подходящих категорий мест. Основой остаётся автоматически собранный городской снимок OpenStreetMap; при нехватке мест сервер точечно обращается к Overpass. К нему могут добавиться только записи открытого каталога Overture Maps, для которых адрес и координаты сверены с независимыми адресными данными; это не доказывает, что названное заведение сейчас работает. Подготовленный, пока выключенный адаптер 2ГИС Places сможет искать заведения по категориям поблизости после проверки прав на показ результатов на нашей карте OSM: ему передаются категория и округлённый примерно до километра центр поиска, без свободного текста запроса, точных координат и данных Telegram. Overpass может кратковременно кешироваться; ответы 2ГИС приложение не кеширует. Если выбран ориентир, итоговые кандидаты ограничиваются коридором движения от старта в его сторону.
3. OpenAI выбирает остановки из сбалансированного по категориям списка до 36 кандидатов. Сервер принимает только ID реально найденных записей OSM, Overture или 2ГИС, проверяет координаты, направление и ограничения времени, затем собирает до трёх разных вариантов без повторения остановок. «Ещё идеи» исключает ранее показанные точки в текущей сессии Mini App. После выбора маршрутов сервер добавляет только сведения о выбранных остановках: явные теги OSM и данные со страницы конкретного филиала на сайте заведения или Visit Astana. За запрос он загружает не более трёх страниц заведений и при необходимости один индекс Visit Astana. Для субъективных или меняющихся свойств сохраняется отдельный ограниченный веб-поиск OpenAI. Сведение показывается только со ссылкой на свой источник; дата проверки страницы не гарантирует актуальность самого места.
4. Для выбранных платных мест сервер может найти опубликованную цену на подходящей странице заведения или через веб-поиск OpenAI. Он проверяет соответствие заведения и филиала, сумму в тенге и тип цены по содержимому источника. Рядом с принятой ценой показаны источник и дата проверки; иначе стоимость остаётся неизвестной. Веб-поиск цен проверяет не более шести выбранных мест за запрос. Если опубликованная цена билета или средний чек выше бюджета на человека, такой вариант опускается ниже. Найденная цена входа, среднего чека или одной позиции не равна полной стоимости маршрута.
5. Карта открыта сразу. До ответа видны только выбранные человеком старт и ориентир; POI и нумерованные остановки появляются после построения маршрута. В результате отдельная плашка показывает фактическое направление от старта до последней остановки. Если нет дорожной геометрии, пунктир обозначает лишь порядок точек; реальный путь открывается во внешней карте. Ориентир задаёт примерную сторону движения, а не точный финиш.
6. Если включено условие доступа для коляски, сервер пропускает только городские места с явным `wheelchair=yes` в OSM. Для коротких пеших переходов он приблизительно оценивает каждый отрезок от старта и между остановками. Режим «Без спешки» ограничивает городской маршрут двумя остановками и выделяет больше времени на каждую в пределах выбранной длительности. Игровой режим по возможности выбирает несколько разных реальных мест; идеи у остановок явно обозначены как идеи приложения, а не сведения о месте. При нехватке подтверждённых мест результат может быть коротким или пустым.

Загородный режим пока использует отдельные проверяемые направления из `data/astana-trips.json`. У него иные требования ко времени и дороге; он не смешивается с городским поиском клубов, кафе и прогулок.

## Запуск и публикация

Нужны Node.js 24+, Telegram-бот от [@BotFather](https://t.me/BotFather), ключ OpenAI и аккаунт Cloudflare.

```powershell
npm ci
npm run build
npm test
```

Локальный `.dev.vars` содержит `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `MINI_APP_URL`. Необязательный поиск через [2ГИС Places API](https://docs.2gis.com/en/api/search/places/overview) подготовлен, но выключен до проверки применимых условий использования с картой OSM; для его разрешённого включения нужны серверные `TWO_GIS_API_KEY` и `TWO_GIS_ENABLED=true`. Без него приложение ищет по OSM/Overpass и сверенной по адресу части Overture. Файл исключён из Git. Шаблон — [.dev.vars.example](.dev.vars.example). Ключи не должны попадать в клиентский код или репозиторий.

Для просмотра интерфейса в браузере: `npm run dev`. Подбор принимает только действительный запуск Mini App через Telegram. Для локальной разработки Worker: `npm run build`, затем `npm run worker:dev`. При работающем локальном Worker команда `npm run smoke:local` проверяет три сценария с тестовой Telegram-подписью; она обращается к OpenAI и расходует небольшую часть баланса ключа.

При первой публикации авторизуйте Wrangler (`npx wrangler login`), выполните `npm run deploy`, затем `npm run secrets:publish -- https://…workers.dev` и `npm run bot:configure -- https://…workers.dev`. Последняя команда задаёт webhook, `/start` и кнопку Mini App. При изменении кода или данных повторите развёртывание; настроенный webhook сохраняется, если адрес Worker не менялся.

## Данные и пределы точности

- Базовый источник городских мест — данные © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL. Городской снимок автоматически извлекается из публикации Geofabrik; подробная запись OSM открывается из соответствующей остановки. Публичный Overpass может быть перегружен, а сведения OSM неполны; приложение не обещает найти буквально все заведения города.
- Дополнительный открытый источник — [Overture Maps Places](https://docs.overturemaps.org/guides/places/). Из машинной очереди 521 записи в маршруты допускается только отобранная выборка с независимо сверенными адресом и координатами; остальные записи остаются исследовательскими. Название и категория такого места всё ещё происходят из Overture, не из адресной сверки, поэтому текущую работу филиала нужно проверить. Записи Overture имеют собственные идентификаторы, происхождение и [атрибуцию поставщика](https://docs.overturemaps.org/attribution/), а не подставной OSM ID. Описание проверки — в [исследовательских данных](data/research/README.md).
- Поиск через [2ГИС Places](https://docs.2gis.com/en/api/search/places/overview) подготовлен как необязательный источник, но в опубликованном приложении не включён: доступные [условия Platform Manager](https://law.2gis.ru/en/platform-manager) не дают однозначного разрешения показывать результаты на карте OSM. После подтверждения права и включения он будет использовать только категорию и округлённый центр области; источник и ссылка на карточку 2ГИС будут указаны у остановки. [Демо-ключ](https://docs.2gis.com/en/platform-manager/subscription/keys) действует месяц, а [лимит Places API составляет 1000 успешных запросов за демо-период](https://docs.2gis.com/en/platform-manager/subscription/pricing). Затем нужна подписка либо иной разрешённый источник.
- Подтверждённые закрытия могут исключаться из подбора отдельно от исходного снимка. Например, [администрация Астаны сообщила о закрытии аквапарка Ailand](https://www.gov.kz/org/astana-nura/press/news/details/1047434?lang=ru), хотя объект сохранился в OSM; запись и источник исключения находятся в `data/astana-place-exclusions.json`.
- Опубликованные цены находятся не для каждого места. Поиск цен ограничен выбранными остановками и доступностью открытых источников; успешные результаты кешируются до шести часов, отсутствие результата — до 30 минут. Цена могла измениться после проверки, а отдельная позиция или вход не покрывают все расходы. Бюджет задаётся на человека; неизвестная стоимость не означает, что место бесплатное или укладывается в бюджет.
- Дополнительные сведения об остановке появляются только из явных тегов OSM или страницы, которая однозначно относится к выбранному филиалу. Для загруженной страницы указываются ссылка и дата проверки; она не означает, что расписание, меню, бронь или условия доступности действуют сейчас. Страница сети без подтверждения конкретного адреса не переносит свои сведения на все филиалы. За запрос сервер загружает не более трёх страниц заведений плюс при необходимости индекс Visit Astana; при недоступности источников свойства остаются неизвестными.
- Наличие мест для компании, актуальная программа клуба, тишина, часы работы и дорожная обстановка не выводятся из одной только категории каталога. Неподтверждённые свойства показываются как неизвестные. Ни один из источников не гарантирует полный список заведений; «Ещё идеи» может исчерпать доступные подходящие места.
- Время пешком и расстояние между точками — приблизительные расчёты. Пунктир на карте не является уличным маршрутом. Для машины и общественного транспорта точное время дороги не заявляется без дорожного источника.
- `wheelchair=yes` — [отметка сообщества OSM о месте](https://wiki.openstreetmap.org/wiki/Key:wheelchair), а не наша проверка входа, туалета, тротуаров, бордюров или пути между местами. Строгий фильтр допускает только записи OSM с такой отметкой; 2ГИС и Overture не получают её по догадке. Неотмеченное место не считается подтверждённо доступным; фильтр может вернуть мало мест или ни одного. Для загородных поездок данных доступности пока недостаточно, поэтому со строгим фильтром они не предлагаются. Отдельно можно свериться с [картой доступности Казахстана](https://inva.gov.kz/ru#map-box); её сведения не подтягиваются в приложение автоматически.
- Условие «короткие переходы» работает только в городской пешей прогулке. Предел примерно 10 минут относится к оценке каждого перехода, но не гарантирует фактическое время или доступность пути. «Без спешки» и микроприключение работают только в городе. Неспешный темп не подтверждает наличие сидячих мест, туалета или тишины. Игровой сценарий не требует GPS подтверждения и не сохраняет историю выполнения.
- Внешняя карта получает координаты старта и остановок, только когда пользователь открывает ссылку маршрута. Технические данные соединения передаются также сервису тайлов при просмотре карты. Старт и выбранный ориентир используются только в текущем запросе; история запросов и координаты не сохраняются в собственной базе. Подробности — [«О данных»](public/privacy.html).
- Вызовы OpenAI, включая `web_search`, расходуют баланс ключа. Кеш и ограничение частоты уменьшают повторные запросы, но не устанавливают общий дневной предел затрат. Для публичной версии задайте [лимит расходов в проекте OpenAI](https://developers.openai.com/api/docs/guides/spend-limits); стоимость поиска и токенов проверяйте на [странице тарифов OpenAI](https://developers.openai.com/api/docs/pricing).
