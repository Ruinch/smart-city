# Рядом — прогулки по Астане в Telegram

Telegram Mini App для первой задачи хакатона: за 30, 60 или 120 минут предлагает 1–3 реальных места в пилотной зоне вокруг Байтерека. У каждой рекомендации есть причина выбора, оценка времени, действие, источник POI и ссылка на пеший маршрут.

## Как работает

1. `scripts/collect-poi.mjs` собирает именованные места из OpenStreetMap через Overpass, добавляет короткие описания из проверяемых тегов и расчётного расстояния, затем сохраняет каталог в `data/pois.json`.
2. Mini App передаёт подписанные данные запуска Telegram, точку старта и пожелания на `/api/recommend`.
3. Worker проверяет подпись Telegram и отбирает POI по расстоянию, времени и формату прогулки. Модель OpenAI получает только этот короткий список с описаниями, выбирает до трёх ID и может предложить короткую идею действия. Сервер проверяет ID и идею, а сведения о месте и время формирует сам. Идея ИИ явно помечена в карточке.
4. Если модель недоступна, детерминированный подбор продолжает работать.

Интерфейс и API размещаются вместе в Cloudflare Worker. История запросов и координаты не сохраняются в собственной базе. [Политика обработки данных](public/privacy.html).

## Подготовка

Нужны Node.js 24+, Telegram-бот от [@BotFather](https://t.me/BotFather), ключ проекта OpenAI и бесплатный аккаунт Cloudflare.

```powershell
npm ci
npm run data:check
npm test
npm run build
```

Локальный файл `.dev.vars` содержит `OPENAI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET` и `MINI_APP_URL`. Он исключён из Git. Шаблон — [.dev.vars.example](.dev.vars.example). Не публикуйте значения ключей и не добавляйте их в клиентский код.

Для просмотра интерфейса в обычном браузере: `npm run dev`. Отправлять запросы на подбор может только Mini App, открытый через Telegram с действительной подписью запуска. Для локальной разработки Worker: `npm run build`, затем `npm run worker:dev`.

## Публикация

1. Создайте бота в BotFather командой `/newbot`; вставьте его токен и ключ OpenAI в `.dev.vars`.
2. Авторизуйте Wrangler: `npx wrangler login`.
3. Выполните `npm run deploy`. Сохраните выданный адрес `https://…workers.dev`.
4. Выполните `npm run secrets:publish -- https://…workers.dev`. Скрипт передаёт четыре значения из `.dev.vars` в секреты Worker без вывода их содержимого.
5. Выполните `npm run bot:configure -- https://…workers.dev`. Скрипт задаёт webhook, команду `/start` и кнопку Mini App в меню бота.
6. На телефоне откройте бота, отправьте `/start`, нажмите кнопку и проверьте подбор. Адрес `/api/health` должен вернуть `status: ok` и размер каталога.

BotFather и Cloudflare могут запросить действия владельца аккаунта при создании бота и первом развёртывании. После обновления `data/pois.json` повторите `npm run deploy`.

## Данные и ограничения

- Первый каталог покрывает область вокруг Байтерека, а не всю Астану. Каждый POI имеет OSM ID, короткое описание с указанием его происхождения и ссылку на исходную запись. Описания основаны на категории, явных тегах и координатах OSM, а не на проверке объекта на месте. Данные: © участники [OpenStreetMap](https://www.openstreetmap.org/copyright), лицензия ODbL.
- Время пешком — оценка по прямой с коэффициентом обхода, а не построенный маршрут. Ссылка открывает маршрут во внешней карте; нажатие передаёт картографическому сервису начальную и конечную точки.
- `visitMinutes` — примерная длительность посещения по категории места. Часы работы, доступность и удобства для детей не считаются подтверждёнными без отдельной проверки. Запрос «открыто сейчас» не получает неподтверждённого ответа.
- Координата `center` у OSM way/relation может быть геометрическим центром, а не входом. Перед публичным запуском нужно проверить входы у рекомендуемых объектов.

## Проверка перед защитой

- Запуск из `/start` и кнопки меню на телефоне.
- Подбор от Байтерека на 30/60/120 минут; выбор «на воздухе», «в помещении», «с ребёнком».
- Отказ в геолокации и запасной ориентир.
- Несколько разных запросов, пустая выдача, недоступный OpenAI.
- Ссылки на OSM и внешний маршрут, подпись оценки времени, страница «О данных».
